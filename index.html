CF800-11H Heated Grip & Seat Coder

Enables the factory heated-grip and heated-seat functions in the instrument cluster, using an OBDLink CX adapter over Bluetooth LE. Every change is read, modified and verified on the device. Before the first write, the original configuration is saved in this browser so that it can be written back with Restore.

Web Bluetooth unavailable in this browser. Open this page in Chrome on Android (or Edge/Opera), served over https://. It will not work in Safari/iOS, or from a file:// link.

Before you start

You need an Android phone with Chrome or Edge, an OBDLink CX adapter, and a battery charger connected to the motorcycle for the whole procedure.

Required to enable Connect. Remembered on this device.

Not connected

Step 1 — Connect

Switch the ignition on (engine off) with the battery charger connected. Plug the OBDLink CX into the diagnostic port, then connect.

Step 2 — Unlock

Opens an extended diagnostic session and performs the security-access handshake with the instrument cluster (DASH, 0x714).

Step 3 — Read configuration

Reads the cluster's identification (part number F187, software F195) and its complete configuration record (F010), then shows the current heating settings and whether this cluster is a confirmed variant. Always read before writing.

The dry run performs steps 2 and 3, reads the cluster's identification, tests the adapter's multi-frame transmit path and shows exactly what would change. It never writes and never enables step 4. Recommended before the first write.

Step 4 — Select and write

Unlocks again immediately before writing so the session cannot have expired, confirms that the adapter can transmit the multi-frame write, writes the record, resets the cluster and reads the record back to verify the change.

Rollback — Restore the original configuration

Writes back the configuration record the cluster held before the first write from this device (saved automatically), or a value you enter from an earlier log: the current F010 line recorded before your first write. Uses the same verified procedure as step 4. Requires a fresh read (step 3); the length must match.

Only bits 4 and 5 of byte 1 are changed; every other byte is written back exactly as read. Do not switch off the ignition or disconnect the adapter between the write and the reset. Note the value logged in step 3 before writing. Step 3 also shows whether your cluster is a confirmed variant.
Advanced (experts only) — raw command console & BCM output test
Experts only. Commands entered here are sent directly to the vehicle without any of the safety checks used by the guided steps. They are not needed for normal use.

Pick the module (sets both header and security mask), then run ② Unlock for it before sending protected commands. Steps 3–4 above are DASH-only and refuse to run while BCM is selected. BCM output test: select BCM, ② Unlock, then I/O-control DID 3503; live level 22 3503 (0/1/2/3 = OFF/MIN/MID/MAX).
