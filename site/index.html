This tool writes configuration data to a control unit in your motorcycle through the diagnostic connector. An incorrect write can give a module an incorrect configuration or make the instrument cluster stop operating.

Use this tool only on a motorcycle that you own, and only at your own risk. Each change sets only two bits in the configuration record (F010): one bit for the heated grips and one bit for the heated seat. All other data stays the same. Before the first write, the tool saves the original value, and ↺ Restore writes it back.

OpenMoto Diag

OpenMoto Diag is an unofficial community tool for the CFMOTO 800MT-X (CF800-11H). It is not affiliated with CFMOTO. It enables the factory functions for the heated grips and the heated seat in the instrument cluster. It uses an OBDLink CX adapter and a Bluetooth Low Energy connection. For each change, the tool reads the configuration record (F010) from the instrument cluster and changes the necessary bits. Then the tool writes the configuration record, reads it again and compares it with the written value. Before the tool writes for the first time, it saves the original F010 value in this browser. You can use ↺ Restore to write the original configuration record to the instrument cluster again.

Web Bluetooth is not available in this browser. Open this page in Chrome on Android. You can also use Edge or Opera. The page address must start with https://. This tool does not operate in Safari or on iOS. If you open this page from a file:// link, this tool does not operate.

Before you start

You must have an Android phone with Chrome or Edge, an OBDLink CX adapter and a battery charger. Connect the battery charger to the motorcycle. Keep the battery charger connected until the procedure is complete.

You must select this check box before you can do step 1. This browser keeps your selection.

Not connected

Step 1 — Connect

Make sure that the battery charger is connected to the motorcycle. Set the ignition switch to ON. Do not start the engine. Connect the OBDLink CX adapter to the diagnostic connector. Then select the ① Connect to OBDLink CX button.

Step 2 — Unlock

This step starts an extended diagnostic session with the instrument cluster (DASH, 0x714). Then it unlocks the instrument cluster with the security access handshake.

Step 3 — Read configuration

This step reads the full configuration record (F010) from the instrument cluster. It also reads the part number (F187) and the software version (F195) of the instrument cluster. Then it shows the current settings for the heated grips and the heated seat. It also shows if this instrument cluster is a confirmed variant. Always do this step before you do step 4 or ↺ Restore.

The dry run does steps 2 and 3. It also reads the identification of the instrument cluster. Then it tests if the adapter can send a multi-frame message (long-message test). Then it shows the exact change that step 4 will make. The dry run never writes to the instrument cluster and never makes step 4 available. We recommend that you do a dry run before you do step 4 for the first time.

Step 4 — Select and write

Step 4 unlocks the instrument cluster again immediately before it writes. This makes sure that the diagnostic session is still active. Then step 4 tests if the adapter can send a multi-frame message (long-message test). Then it writes the configuration record and resets the instrument cluster. Then it reads the configuration record again and compares it with the written value. If a check box is not selected, step 4 does not change the bit for that function.

Rollback — Restore the original configuration

↺ Restore writes the original configuration record to the instrument cluster again. Before step 4 writes for the first time, this tool automatically saves the original F010 value in this browser and shows it in the field. You can also enter the current F010 value that an earlier log showed before your first write. ↺ Restore uses the same write procedure as step 4. Before you use ↺ Restore, do step 3. The value in the field must have the same length as the configuration record in the instrument cluster. If you used this tool at the earlier address untiring1337.github.io/openmoto-diag, your original F010 value is saved at that address. Open that address to see it.

Do not set the ignition switch to OFF or disconnect the adapter until step 4 or ↺ Restore is complete. If you do this, the configuration in the instrument cluster can be unknown or incomplete. Before you do step 4, keep a copy of the current F010 value that step 3 shows in the log. Step 4 changes only bits 4 and 5 of byte 1. All other bytes keep the values that step 3 read. Step 3 also shows if your instrument cluster is a confirmed variant.
Advanced (for experts only) — raw command console & BCM output test
Use this section only if you are an expert. This console sends your commands directly to the motorcycle. It does not do any of the safety checks of the guided steps. This console is not necessary for normal use.

Select a module to set the header and the security mask for that module. Before you send protected commands to this module, select ② Start session and unlock. If BCM is selected, steps 3 and 4, the dry run and ↺ Restore do not start, because they are for DASH only. For the BCM output test, first do the two instructions above for BCM. Then send an I/O control command for DID 3503. To read the live output level, send 22 3503 (0 = OFF, 1 = MIN, 2 = MID, 3 = MAX).
